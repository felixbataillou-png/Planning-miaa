Il s'agit d'un projet pour une asso caritative.

Le but est de créer un planning dynamique pour que les bénévoles puissent s'inscrire plus facilement et plus intuitivement. 
A ce jour le processus d'inscritpion est laborieux : il faut envoyer un mail pour savoir s'il y a de la place pour ensuite pouvoir s'inscrire

Ici nous proposons une solution permettant aux bénévole d'avoir une visibilité des disponiilité sur 2 semaines et de pouvoir faire une demande directement sur le site

Il a fallut également créer une page "admin" pour permettre aux personnes en charge du planning de bien gérer les personnes inscrites et les changement éventuel

Le tout avec un peu d'automatisation via les plateforme Supabase et Resend
